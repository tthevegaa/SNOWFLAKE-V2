SNOWFLAKE-V2

Academic management system developed in Java with SQLite, JDBC and BCrypt.

Features

- Student, Teacher and Administrator roles
- SQLite persistent database
- JDBC integration
- BCrypt password hashing
- SecureRandom password generation
- Academic groups and subjects
- Class schedules
- Student enrollments
- Grade management
- Transactions
- Referential integrity
